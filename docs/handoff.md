## 3. ユーザーと決めたこと

CLAUDE.md の「11. 決まったこと」にも同じことを書いている。

- モデルは MMD 準標準。骨の名前は日本語のまま保つ。
- ライセンスは GPL-3.0-or-later。
- ロードマップの A9・A14・4章（基本ルール）は消した（ユーザーの判断）。
- VRM・Mixamo の hips はセンターに対応させる（convert_pmx.py の HUMAN_BONES に合わせる）。
- VRM・Mixamo のつま先の骨（指の付け根）も「つま先」に対応させる。
- 肘・ヒジ＝ひじ、膝・ヒザ＝ひざ、人差指・人差し指＝人指、捻＝捩 を辞書に入れる。
- 揺れ物の骨（髪・スカート・リボンなど）は、人の形ではない骨として扱い、ユーザーに聞かない。
- 辺に3つ以上の面がつく所は黄。
- アプリのカメラは縦画面で、ユーザーが 360° 動かせる。だから「見える」は、まわり全体（`orbit_views`）のどれかから見えること。下から見上げる向きも入る。
- ひざの逆曲がりは、まちがえて赤にしない。向きが決まらないときは灰。一部が測れない物は灰でよい。
- 骨の跳び（1フレーム 30°）は仮。本物の VMD で決め直す。
- 登録カードの指紋は、モデル自身の座標で取る。置き場所が変わっただけなら、別に知らせる。
- 腕の下がり角は、アプリ（convert_pmx.py）と同じ測り方。
- 体・髪・服が1つのメッシュのモデルは、材質ごとに種類を選べる。
- 辞書に無い骨への答えは、カードに覚える（同じモデルのときだけ持ち越す）。
- E1 で黄にするもの：アプリのヒューマノイドの骨が足りない、convert_blend.py が知らないお知らせを出した。
- 4本までに絞ったことで少しでも形が変われば黄（0.5mm 以上は赤）。

## 4. 分かっている問題

- **Blender 5.2.2 の USD の書き出し**（`only_deform_bones=True`）は、変形しない骨が変形する骨の間にあると、片側だけ骨の一覧から落とすことがある。試し用モデルでは 腰キャンセル左 が落ち、休みの姿勢の左脚が最大 14 cm ずれる。E2 はこれを赤で出す。挟まった骨を「変形する」にすると起きない。PMX から読んだモデルは骨が全部「変形する」なので、たぶん起きない。本物のモデルで E2 をかけて確かめる。起きたら紅魔館の側で直す（案を出す）。
- convert_blend.py を動かすたびに、紅魔館の `tools/model-converter/__pycache__` ができる。紅魔館の `.gitignore` に `__pycache__/` を足すとよい（紅魔館の側への提案）。
- E1 は空でない出力フォルダを断る。Mac の Finder が `.DS_Store` を作ると断られるので、画面から書き出すときは、新しいフォルダを道具が作る。
- E2 は Blender のシェイプキーの今の値で比べる。表情のキーが 0 でないと、ずれとして出る（比べる前に 0 にするか、写しで 0 にする）。
- 本物の MMD の体は閉じていない（服の下の肌を消してある、首や手首で切れている）ことが多い。A5 の服のめり込みは、閉じていない所で灰になる。

## 5. 決めることが残っていること（作る係が出した問い。おすすめを添える）

- 画面の言語：いまの既定は「自動」（Blender の言語が日本語なら日本語、それ以外は英語）。CLAUDE.md は「画面は日本語」なので、既定を「日本語」にするのがおすすめ。
- A5 の確かめで、見え方（62 方向）を既定で使うか：段階1の基準は「アプリのカメラから見える赤」なので、A10 ができたら既定で使うのがおすすめ。今は使わない（隠れためり込みも赤に数える、きびしい側）。
- A5：T ポーズのモデルでは、腕を上げるポーズが上がりすぎる。登録カードの腕の下がり角で直すのがおすすめ。
- A1：骨を少し直しただけでも、登録をやり直すと利用条件などの答えが消える（同じモデルかの比べがきびしい）。利用条件だけは、骨の名前が同じなら持ち越すのがおすすめ。
- A1：登録カードの骨の対応に「揺れ物の骨」を入れるか（`sway_extras`）。報告で「揺れ物の骨 N 本」と言うために、入れるのがおすすめ。
- A1：部品の種類の名前（PART_KIND_LABELS など）を `texts/` に移す。
- A6：「前の版」はいちばん新しい番号の版。古い版を開いて作業したときの扱いを決める。
- A6：ウェイトの比べの幅を、基準の数字として別に持つか（今は WEIGHT_EPSILON を使う）。
- E2：ポーズで骨が動かなかったときの灰が、ほかのポーズの黄を隠す。灰と黄を両方出すのがおすすめ。
