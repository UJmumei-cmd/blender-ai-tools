### 画面のボタン（段階1。3D ビューの右の欄「AI の道具」）

- 「確かめと書き出し」の欄：
  - 「版を保存」（目録 `versions.save`）・「前の版と比べる」（`versions.compare_with_previous` → 報告 `versions`）。保存した版の一覧（新しい版が上）。
  - 「書き出して確かめる」：紅魔館の場所が無い・正しくない、版が無いときは断る。書き出すのは、いちばん新しい保存した版。出力は作業フォルダの `exports/<版の名前>_<仕事の id>/`（毎回新しいフォルダ。アプリの Model フォルダの中なら仕事を出す前に断る）。値は仕事を出す前に `catalog.validate_call` で確かめる。
  - 「確かめの動き」：値は `{"visibility": true}`。入力は、仕事を順番待ちに入れたすぐあとに保存する、いまの形の写し（仕事のフォルダの `input.blend`）。写しが置けなければ仕事を取り消して消す。
- 「裏の仕事」の欄：新しい仕事が上、10 件まで。道具の名前・ようす・進み具合（段と説明）・理由の文。ボタンは［中止］（終わっていない仕事）・［結果を見る］（終わって報告を作る道具）・［一覧から消す］（終わった仕事）。裏の係が終わりを書いたがプロセスがまだ残っている仕事は「片付け中」（ボタンなし）。
- 「報告」の欄：種類と時刻、いちばん上の一言（いちばん重い信号の色）、赤の数と基準（`decisions.json` の `baselines`）の比べ、［HTML］［開く］［基準にする］、1件ずつ信号・値・理由（緑でない物）と［直す（おすすめ）］［このままでよい］［あとで］、いまの答えと消すボタン。40 件まで。
- 仕事が「終わりました」になり、その道具が報告を作る物（書き出して確かめる・確かめの動き）なら、結果（result.json）から報告を作って自動で出す。
- `ui/background.py`：JobQueue は、仕事のフォルダ（作業フォルダの `jobs/`）がもうあるとき（register・別のファイルを開いたとき・保存したとき）か、仕事を出したときだけ作る。作ったら `recover()` のあとタイマー（`start_polling`）。別のファイルを開くとタイマーを止めてつなぎ直す。unregister でタイマーを止める。パネルは覚えた一覧を読むだけ（描くときに何も変えない）。
- 開いている .blend は保存も上書きもしない（テストで指紋を比べている）。

## 4. 分かっている問題

- **Blender 5.2.2 の USD の書き出し**（`only_deform_bones=True`）は、変形しない骨が変形する骨の間にあると、片側だけ骨の一覧から落とすことがある。試し用モデルでは 腰キャンセル左 が落ち、休みの姿勢の左脚が最大 14 cm ずれる。E2 はこれを赤で出す。挟まった骨を「変形する」にすると起きない。PMX から読んだモデルは骨が全部「変形する」なので、たぶん起きない。本物のモデルで E2 をかけて確かめる。起きたら紅魔館の側で直す（案を出す）。
- convert_blend.py を動かすたびに、紅魔館の `tools/model-converter/__pycache__` ができる。紅魔館の `.gitignore` に `__pycache__/` を足すとよい（紅魔館の側への提案）。
- E1 は空でない出力フォルダを断る。Mac の Finder が `.DS_Store` を作ると断られるので、画面から書き出すときは、新しいフォルダを道具が作る。
- E2 は Blender のシェイプキーの今の値で比べる。表情のキーが 0 でないと、ずれとして出る（比べる前に 0 にするか、写しで 0 にする）。
- 本物の MMD の体は閉じていない（服の下の肌を消してある、首や手首で切れている）ことが多い。A5 の服のめり込みは、閉じていない所で灰になる。
- A10：1つの仕事のフォルダに `JobQueue` を2つ作ると（同じ .blend を2つの Blender で開くなど）、同じ仕事を2回始めることがある。画面では1つだけ作る。前の回の裏の Blender の pid が別のプログラムに使い回されていると、それが終わるまで待つ（まれ。「失敗にする」ボタンを画面に足すかは決めていない）。
- A10：入力の .blend を守るのは「終わったあとに指紋を比べる」方式。道具が `save_mainfile()` を場所なしで呼ぶと入力が上書きされてから失敗になる。重い道具は新しい場所にだけ保存し、画面は版の写しだけを渡す。
- A10：裏の Blender は `--factory-startup` なので mmd_tools が入っていない。M1（VMD・VPD）では、裏で mmd_tools を有効にするか決める。
- `motion.run_course` は、まとめ（`summarize_course`）の `details["counts"]` のキーが信号（Signal）だったので、結果を JSON にできず、どこから呼んでも失敗していた。キーを信号の名前（"red" など）にして直した（試しが無かった。いまは本物の裏の Blender で動かす試しがある）。`details["per_pose"]` の信号は JSON では数（0〜3）になる。
- 確かめの動きの進み具合は、ポーズの前に書くので、最後は「(ポーズの数 − 1) / ポーズの数」で終わる（終わりましたの表示には出ない）。
- 前の版との比べの報告で、同じオブジェクト・同じ種類の変化が2つ以上ある（シェイプキーごとの形の変化など）と、2つ目から id の後ろに出た順の番号（`/2` など）を付ける。結果にシェイプキーの名前が入っていないため。前の版で順番が変わると、答えが別の項目に付くことがある（結果に名前を足すなら、道具の版を上げる）。
- 仕事が終わると、その結果の報告に自動で置きかわる（見ていた報告は「結果を見る」か、比べ直しで戻す）。
- 画面の作業フォルダの設定を変えたときは、次に仕事を出すときに新しい場所の順番待ちにつなぎ直す（前の場所で動いている裏の Blender は止めない）。

## 7. デスクトップでの始め方

### 7.1 準備

1. このリポジトリを取ってきて、ブランチ `claude/keen-hopper-m4ej6g` にする（`git fetch origin` → `git checkout claude/keen-hopper-m4ej6g`）。
2. Blender 5.2（5.2.2 LTS で作った）を入れる。Mac は `/Applications/Blender.app`。ほかの場所なら環境変数 `BLENDER` に入れる。
3. `tools/run_tests.sh` で全部のテストが通ることを確かめる（約 1〜2 分）。
4. 紅魔館のリポジトリがあれば、`BLENDER_AI_TOOLS_KOUMAKAN_REPO=<紅魔館の場所> tools/run_tests.sh` で、本物の書き出しのテストも通す（クラウドでは、もらった convert_blend.py と convert_pmx.py の写しをリポジトリの外に置いて使っていた）。
5. `tools/build_extension.sh` で `dist/blender_ai_tools-0.1.0.zip` を作り、Blender の「編集」→「プリファレンス」→「機能拡張」→ 右上のメニュー →「ディスクからインストール」で入れる。
6. プリファレンスの「AI の道具」で、紅魔館のリポジトリの場所を入れる（Blender の場所と作業フォルダは空のままでよい）。

### 7.2 手で押して確かめる（クラウドではできなかった所）

`tools/make_sample_model.sh` で `samples/sample_model.blend` を作って開き、3D ビューで N キー → 「AI の道具」のタブで、上から順に押す。

1. 登録する → 部品の種類（Body は体、Skirt は服・スカート）を選ぶ → 確かめる。
2. 骨の名前を調べる（試し用モデルは準標準どおりなので、聞かれる骨は無い）。
3. 版を保存する → `sample_model_v001.blend` が隣にでき、開いているファイルはそのまま。
4. 何か少し動かしてから、前の版と比べる → 報告に、変わった所が赤で出る。
5. 確かめの動き → 「裏の仕事」に進み具合が出る（ポーズ 44 個、見え方つきなので数分〜十数分）。画面は固まらない。途中で［中止］も試す。
6. もう一度、確かめの動き → 終わると「報告」に結果が自動で出る。1件ずつ［このままでよい］などを押し、［HTML］→［開く］でブラウザに出るか。
7. 書き出して確かめる → 作業フォルダの `exports/` に `character.usdz` と `character_rig.json` ができ、報告にずれ（0.5mm 未満）と 4本に絞った影響（黄）が出る。アプリの Model フォルダには何も書かれていないこと。
8. Blender を閉じて開き直す → 「裏の仕事」の一覧が残っていること。

おかしかった所は、見たまま（画面の文、コンソールの出力、作業フォルダの `jobs/<仕事>/log.txt`）を Claude に渡す。
